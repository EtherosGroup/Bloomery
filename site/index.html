Minecraft: Java Edition, launched from your terminal.

Bloomery is a free, open-source launcher for Minecraft: Java Edition. It installs versions and mod loaders, signs in with your own Microsoft account, and starts the game — with no runtime dependencies beyond Node.js.

Install Source code npm package
bloomery — sample session 
$ bloomery folder add ~/Game/Minecraft
$ bloomery auth login --type microsoft
$ bloomery install 1.20.6 --loader fabric@latest
$ bloomery launch 1.20.6

What it does

Bloomery keeps the standard .minecraft layout used by other launchers, so the same game folder can be shared between them.

Isolated versions

Every version lives in its own directory under versions/<id>/, with its own mods, saves and config.

Vanilla and mod loaders

Installs vanilla releases plus Fabric, Quilt, Forge and NeoForge, at a pinned loader version or the latest.

Microsoft and offline accounts

Sign in with the Microsoft account that owns the game, or play offline on LAN and private servers.

Java you already have

Scans installed JDKs and JREs, then picks one that satisfies the version's requirement.

No runtime dependencies

Plain Node.js and the standard library. Nothing bundled, nothing downloaded behind your back.

Scriptable

Every command takes --json, and --dry-run shows the exact command line before anything starts.

Mirror and proxy aware

Downloads from official Mojang sources, with an optional BMCLAPI mirror and HTTP proxy support.

Open source

Apache-2.0, developed in the open at EtherosGroup/Bloomery.

How Microsoft sign-in works

Bloomery uses the OAuth 2.0 device authorization grant, the flow designed for apps without a browser — like a command-line tool.

  1. Start the sign-in

    bloomery auth login --type microsoft prints a short code and a link to Microsoft's sign-in page.

  2. Approve it on Microsoft's own page

    You open the link and enter the code yourself. Your password and any multi-factor prompt are handled entirely by Microsoft.

  3. The launcher gets tokens, not credentials

    Bloomery exchanges the approved sign-in for an Xbox Live token, an XSTS token and a Minecraft access token, all of which stay on your machine.

Bloomery never sees your password. Sign-in happens on Microsoft's page; the launcher only receives the resulting tokens, stored locally in your own configuration directory with owner-only permissions. See the privacy policy for the details.

Install

Requires Node.js 20 or newer, and a Minecraft: Java Edition account you own if you want to play online. 

npm install -g bloomery

Or build from source:

npm install -g github:EtherosGroup/Bloomery

Then check what is available with bloomery --help, add your game folder with bloomery folder add <dir>, and start a version with bloomery launch <version>.
